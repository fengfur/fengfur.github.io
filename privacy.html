隱私權政策

最後更新：2026年10月24日

本政策適用於 fengfur 維護的「幻幀製造局影片上傳」及本說明網站。工具供頻道擁有者個人使用，透過 YouTube API Services 上傳自行製作或合法持有的影片並核對結果，不下載其他人的 YouTube 影片，也不向網站訪客開放帳號連接。

資料範圍與用途

擁有者自行提供的資料包括原創影片、圖片、劇本、提示詞、文案及製作紀錄。這些資料不是從 Google API 取得的影片內容。

使用上傳功能時，工具另處理 Google 授權憑證、授權頻道的名稱與識別資料，以及上傳後回傳的影片識別碼、處理狀態與可見性。用途限於確認正確頻道、上傳選定影片、核對結果、維護授權及避免重複上傳。本工具不接收或保存 Google 帳號密碼，不要求 Gmail 或聯絡人權限，也不讀取觀看紀錄。

保存與安全

授權憑證以作業系統提供的使用者層級加密保存在擁有者本機；影片與製作資料保存在擁有者管理的儲存設備。與 Google／YouTube 的資料傳輸使用加密連線。授權憑證不放入本公開網站、一般製作紀錄或 AI 提示詞。

授權有效且提供功能仍有必要時，工具保存授權憑證。頻道與影片狀態資料隨每日作業定期重新核對；一般 API 快取若滿30日仍無法更新，會清除或去識別。此規則同樣適用於本工具管理的歸檔與交付副本。

原創影片、圖片、劇本、提示詞、文案及製作紀錄主體不因上述30日規則而刪除；其中嵌入的 Google API 回傳欄位依同一規則更新或清理。不含 Google 識別資料的本機作業紀錄與影片雜湊可保留，供追溯製作及防止重複上傳。

資料傳送與協助服務

選定影片、標題、說明、標記及上傳所需資料會傳送給 Google／YouTube，不會因為使用本工具就放入本公開網站。Google 的資料處理方式請見Google 隱私權政策。

擁有者使用 OpenAI 的 Codex 或影像生成服務協助製作、審查及操作時，經其授權提交的原創素材、提示詞與必要的製作或上傳結果摘要，可能由 OpenAI 處理。Google API 資料僅能在提供上述功能所需且經擁有者明確授權的範圍內提供；授權憑證不提交給這些協助服務。相關處理及保存方式依OpenAI 隱私權政策及擁有者的帳戶資料控制設定辦理。

本工具不出售 Google 使用者資料、不提供給廣告商，也不將這些資料作為模型訓練資料。Google API 資料的使用與轉移受Google API Services User Data Policy及適用的 Limited Use 要求約束。

撤銷授權與資料刪除

你可隨時在Google 帳戶的第三方存取權設定移除本工具的授權。工具檢查授權失效後會停止使用該授權並清理相關 API 資料；透過 Google 帳戶撤銷的相關資料最遲於撤銷後30個日曆日內清理。暫時斷線不會被當作你已撤銷授權。

如向維護者提出有效的資料刪除要求，會儘速處理，最遲於收到要求後7個日曆日內清理本工具保存的相關 Google 授權及 API 資料。由工具執行刪除流程時，會停止後續上傳並嘗試向 Google 撤銷憑證；若無法完成遠端撤銷，會告知你使用 Google 帳戶設定完成。本工具管理的副本一併處理；另行匯出的離線備份由維護者按相同期限處理。

刪除本工具的 Google 資料不會自動刪除原創製作素材，也不會刪除或變更 YouTube 上的影片。YouTube 影片須另在YouTube Studio管理或刪除。重新使用上傳功能須由擁有者明確重新授權。

網站瀏覽

本網站不接受登入或上傳，沒有自行加入的追蹤、廣告、分析程式、cookies 或表單。GitHub Pages 託管服務可能為提供及保護網站記錄 IP 位址等連線資料，請見GitHub 隱私權聲明。點選外部服務連結後，該服務依其隱私權政策處理資料。

聯絡與政策更新

如有隱私權疑問或資料刪除需求，請寄信至 fengfur.codex@gmail.com 聯絡維護者。請勿提供密碼、授權碼或存取憑證。

資料處理方式變更時，會更新本政策及日期；如涉及新增 Google 資料用途或分享範圍，會先取得相應同意。
