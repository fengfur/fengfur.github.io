隱私權政策

最後更新：2026年10月23日

本政策適用於 fengfur 維護的「幻幀製造局影片上傳」及本說明網站。工具供頻道擁有者個人使用，使用 YouTube API Services 上傳影片及核對結果，不向訪客開放帳號連接。

存取哪些資料、用來做什麼

工具處理必要的Google授權資料、頻道名稱與識別資料、所選影片及其標題、說明和標記，以及上傳結果紀錄。這些資料用於確認正確頻道、上傳私人影片、核對狀態及避免重複上傳。本工具不接收或保存Google帳號密碼。

保存與分享

授權資料加密保存在擁有者本機；影片、文案和上傳紀錄保存在擁有者管理的儲存設備。所選影片與必要資料會傳送給Google／YouTube，不會放入本公開網站。擁有者選用的操作協助服務可能處理其提交的對話或製作紀錄，依該服務的設定與政策處理；授權憑證不應提交給這些服務。

本工具不出售資料、不將Google使用者資料提供給廣告商，也不以這些資料訓練機器學習模型。透過Google API取得資料的使用與轉移，遵守Google API Services User Data Policy，包括Limited Use要求。Google的資料處理方式請見Google隱私權政策。

撤銷授權與刪除資料

你可隨時在Google帳戶的第三方連結移除本工具的存取權。撤銷後須重新授權才能繼續存取，但不會自動刪除已上傳的YouTube影片。

工具沒有自動到期刪除所有紀錄的功能。擁有者可先停止相關作業，再刪除本機授權資料、上傳紀錄、影片及備份；需要協助時，可聯絡維護者。YouTube上的影片須另在YouTube Studio管理或刪除。

網站瀏覽

本網站不接受登入或上傳，沒有自行加入的追蹤、廣告、分析程式、cookies或表單。GitHub Pages託管服務可能為提供及保護網站而記錄IP位址等連線資料，請見GitHub隱私權聲明。

聯絡與更新

問題或資料處理需求可透過維護者GitHub頁所列聯絡方式或網站儲存庫提出。請勿在公開留言貼上私人影片、密碼或授權憑證。資料處理方式變更時，會更新本政策及日期。
